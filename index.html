ADDITIONAL FILE 01

THE FLIGHT ANOMALY

European Flight Monitoring System

WHAT I BUILT Developed a Python pipeline that retrieves aviation data through the AviationStack API, stores structured flight records in SQLite, and analyzes airline delay patterns.

THE CHALLENGE Flight information changes over time. A flight initially marked as scheduled may later receive an actual departure time, creating a risk of duplicate records or inaccurate analysis.

HOW I ADDRESSED IT Used composite uniqueness constraints and SQL upserts to update existing flights instead of duplicating them. Added validation and automated tests to verify update behavior.

WHAT I LEARNED Reliable analytics starts with reliable data, not just good queries.

TECH STACK: Python · AviationStack API · Requests · SQLite · SQL
ADDITIONAL FILE 02

THE RESEARCH TRAIL

PubMed Fetch Research Papers

WHAT I BUILT Built a Python tool that searches PubMed, extracts biomedical publication metadata, identifies potentially industry-linked papers, and exports structured results to CSV.

THE CHALLENGE Identifying pharmaceutical or biotechnology affiliations wasn't straightforward. Publication metadata doesn't always reveal an author's actual organizational affiliation.

HOW I ADDRESSED IT Combined PubMed APIs with XML parsing and keyword-based filtering to create an initial screening workflow, while recognizing that keyword matches aren't definitive proof.

WHAT I LEARNED Extracting information and interpreting its meaning are two different problems.

TECH STACK: Python · PubMed API · Requests · XML · CSV
ADDITIONAL FILE 03

THE ALTERED CANVAS

Swift Style — Neural Style Transfer

WHAT I BUILT Implemented a CNN-based fast neural style transfer approach that transforms photographs into artistic images while preserving their recognizable content.

THE CHALLENGE Getting the deep-learning workflow running on Windows required dealing with environment differences and compatibility requirements in a setup originally oriented toward Unix-based tools.

HOW I ADDRESSED IT Worked through dependency configuration, execution paths, and framework compatibility while adapting the image-processing and model-execution workflow.

WHAT I LEARNED Understanding neural networks is only part of ML engineering. Making the entire pipeline executable and reproducible matters just as much.

TECH STACK: PyTorch · CNN · Perceptual Loss · Computer Vision
